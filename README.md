# Hyejin Yoo — Personal Website

This folder is ready for GitHub Pages.

## Upload now
Replace the existing `index.html` in your `hyejinU.github.io` repository with this `index.html`.

## Add later

### Profile photo
Upload your photo to the repository root with this exact filename:

`profile.jpg`

The placeholder initials will automatically disappear when the image exists.

### CV
Upload your CV to the repository root with this exact filename:

`CV_HyejinYoo.pdf`

The CV buttons are hidden until the PDF exists, and will automatically appear after you upload it.

## Repository structure

```text
hyejinU.github.io/
├── index.html
├── profile.jpg          # add later
└── CV_HyejinYoo.pdf     # add later
```

After committing changes, GitHub Pages normally updates within a few minutes.
